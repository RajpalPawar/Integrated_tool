# Suma Integrated Project

This workspace keeps the existing Java + Spring Boot, React, and PostgreSQL application as its foundation and adds Suma Tracking capabilities incrementally.

Start with the original application README in `README.md` for setup requirements. Review `INTEGRATION_STATUS.md` for the changes in this integration build, the attendance API, permission requirements, and validation limitations.

The original Suma Tracking code is retained in `reference/suma-tracking` for comparison. Do not run both backends against the same database. The integrated application is intended to use one Spring Boot backend and one PostgreSQL database.
